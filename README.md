# CodeAlpha_HangmanGame 🎮

## Description
This is a functional, text-based Hangman game developed in Python as part of my internship at CodeAlpha. [cite_start]The goal of the project was to create a game where a player guesses a word one letter at a time within a limited number of attempts[cite: 27, 28].

## Features
* [cite_start]**Random Word Selection:** The game picks a random word from a predefined dictionary[cite: 29, 32].
* **Hint System:** Players can request a hint to help identify the word (costs 2 lives).
* [cite_start]**Lives Management:** The player is limited to 6 incorrect guesses[cite: 30].
* **Interactive Feedback:** Displays guessed letters and remaining lives after each turn.

## Key Concepts Used
* [cite_start]**Random Module:** For selecting words from the dictionary[cite: 32].
* [cite_start]**Loops:** Using `while` loops to maintain the game state[cite: 32].
* [cite_start]**Conditional Logic:** Using `if-else` and `if-elif` for input validation and checking guesses[cite: 32].
* [cite_start]**Data Structures:** Utilizing dictionaries to store words and their respective hints, and lists to track guessed letters[cite: 32].
